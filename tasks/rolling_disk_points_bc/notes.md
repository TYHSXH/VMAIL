# 例7-10 曲柄驱动纯滚圆盘

## 真实问题

曲柄 OA 通过连杆 AB 驱动圆盘，圆盘沿固定圆弧纯滚。要在图示位置研究圆盘中心 B 和边缘点 C 的速度与加速度。

## 给定条件

- OA = AB = R = 1 m。
- 圆盘半径 r = 0.5 m。
- 图示瞬时 OA 竖直，AB 水平，B 为圆盘中心，C 为圆盘最右侧的材料点。
- 按附图箭头，图示曲柄转向在模型中对应 crank_speed = -2 rad/s。
- 题设曲柄角加速度为零；数值验证时同时观察实际曲柄角加速度是否足够接近零。

## 模型和假设

- 机构在水平 x-y 平面内运动，忽略重力和摩擦对运动学的影响。
- 圆弧是可视化导轨。圆盘中心 B 由 disk_orbit 约束在以 O1 为圆心、R-r=0.5 m 为半径的轨道上。
- pure_rolling 约束把圆盘自转与中心的公转角联系起来，表示对固定圆弧无滑动纯滚。
- 本题只考察一个瞬时，因此采用题图姿态处保留到二阶的局部运动学约束来联动曲柄、连杆和圆盘。它保留该瞬时的位置、速度和加速度关系，并避免机构远离题图后经过死点。
- 初始姿态位于题图前 `0.1 rad`，初始广义速度与约束相容；题图方向对应 `crank_speed=-2`。

## 网页实验步骤

1. 在“控制”页把 crank_speed 设为 -2 rad/s。
2. 点击“开始”，机构从题图前的邻近姿态平稳进入题图瞬时。
3. 当曲柄转角最接近 0 rad（约 `t=0.05 s`）时暂停。
4. 从数据页读取 B、C 两点的速度大小和加速度大小，并同时检查曲柄角速度和角加速度。
5. 需要速度、加速度方向时，导出当前数据，使用 vx、vy、ax、ay 分量。

## 核心观测量

- site.point_b.velocity.magnitude：B 点速度大小，m/s。
- site.point_b.acceleration.magnitude：B 点加速度大小，m/s²。
- site.point_c.velocity.magnitude：C 点速度大小，m/s。
- site.point_c.acceleration.magnitude：C 点加速度大小，m/s²。
- joint.crank_hinge.position / velocity / acceleration：用于确认取值时刻和驱动条件。

## 结果解读

任务不预置题目解答。两张主要曲线只对比 B、C 点的速度大小和加速度大小；CSV 仍保留平面分量，便于用理论力学公式独立验证。该任务是题图瞬时的局部实验，不用于模拟曲柄完整回转。
