# 例7-10 曲柄驱动纯滚圆盘

## 修改后的研究问题

曲柄 OA 通过连杆 AB 驱动圆盘，圆盘沿固定圆弧纯滚。原教材尺寸不能让曲柄完整回转；本任务按实验要求修改杆长，研究完整回转过程中圆盘中心 B 和边缘材料点 C 的速度与加速度。

## 给定条件

- OA = 0.4 m，AB = 1.8 m。
- 固定圆弧半径 R = 1 m，圆盘半径 r = 0.5 m，因此圆盘中心轨道半径 O1B = R-r = 0.5 m。
- 固定点 O、O1 的位置保持不变。
- 曲柄顺时针匀速目标对应 crank_speed = -2 rad/s。

## 模型和假设

- 机构在水平 x-y 平面内运动，忽略重力和摩擦对运动学的影响。
- 圆弧是可视化导轨。圆盘中心 B 由 disk_orbit 约束在以 O1 为圆心、R-r=0.5 m 为半径的轨道上。
- `pin_b` 是连杆末端与圆盘中心 B 之间的真实闭环铰接约束，在完整回转范围内持续成立。
- `pure_rolling` 约束把圆盘自转与中心的公转角联系起来，表示对固定圆弧无滑动纯滚。
- 曲柄关节没有角度限位；修改后的长度满足完整回转条件。
- C 是固定在圆盘上的 site 观测点。此前中心 B 到 C 的彩色细杆是模型中的 `disk_radius_mark` 可视化几何体，不是 site 自动生成，本版本已经删除。

## 网页实验步骤

1. 在“控制”页把 crank_speed 设为 -2 rad/s。
2. 点击“开始”，默认运行 3.2 s 后自动暂停；曲柄在约 3.142 s 内完成一周。
3. 从数据页读取完整周期内 B、C 两点的速度大小和加速度大小，并同时检查曲柄角速度。
5. 需要速度、加速度方向时，导出当前数据，使用 vx、vy、ax、ay 分量。

## 核心观测量

- site.point_b.velocity.magnitude：B 点速度大小，m/s。
- site.point_b.acceleration.magnitude：B 点加速度大小，m/s²。
- site.point_c.velocity.magnitude：C 点速度大小，m/s。
- site.point_c.acceleration.magnitude：C 点加速度大小，m/s²。
- joint.crank_hinge.position / velocity / acceleration：用于确认取值时刻和驱动条件。

## 结果解读

任务不预置理论解答。两张主要曲线只对比 B、C 点的速度大小和加速度大小；CSV 仍保留平面分量。当前模型是修改尺寸后的全回转实验，不再代表教材原尺寸的瞬时算例。
