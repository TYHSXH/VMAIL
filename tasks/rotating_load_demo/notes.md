# 变方向外力与偏心力矩

杆在水平面内运动，忽略重力与碰撞。两个滑动自由度与一个转动自由度描述平面运动，采用线性和转动黏性阻尼。

## 操作

1. 在参数中调整基准力、波动频率、方向转速和力偶幅值，应用参数。
2. 在控制页查看自动加载规律，点击开始，在数据页对照运动与实际载荷曲线。
3. 将力偶幅值设为零，观察杆端偏心力仍然可以产生转动。
4. 将方向转速设为零，比较固定方向与旋转方向载荷。

外力大小为 $F(t)=A[1+0.3\sin(2\pi f t)]$，方向角为 $\theta(t)=\omega t$。两个分量按世界坐标系给出，施加于杆端 B 点。额外力偶为 $M_z(t)=M_0\sin(2\pi f t)$。

数据中的载荷力矩是关于杆质心的总力矩，包含杆端力的偏心力矩与额外力偶；不含阻尼等其他物理作用。
