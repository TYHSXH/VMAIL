# 铅垂杆推动楔块（题 6-14）

## 实验目的
观察无摩擦楔块与铅垂杆的加速度关系，验证 $a_B=a_C\tan\theta$ 以及质量比对加速度的影响。

## 操作步骤
1. 在“参数与控制”页保持默认 m = 2 kg、m_c = 4 kg，点击开始，运行 1–2 s 观察加速度曲线进入稳态。
2. 暂停并修改 `rod_mass`，应用参数并重载模型，重置后再次运行，比较两条曲线的稳态加速度。
3. 再修改 `wedge_mass`，重复上述过程，记录 $a_C$、$a_B$。
4. 用数据页导出当前数据，按 notes.md 的公式校核 $|a_z|/a_x=\tan30^\circ=0.5774$。

## 注意
- 初始约 0.045 s 内杆自由下落（球头与斜面间留有 1 cm 间隙），稳态值请取 $t>0.1$ s。
- 加速度符号：楔块向右为正，杆向上为正，故稳态时 $a_z<0$。
