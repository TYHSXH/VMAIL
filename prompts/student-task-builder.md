# Student Prompt: Create a New VMAIL Task

把下面这段复制到 AI coding 工具中。使用前，请确保 AI 已经打开 VMAIL 项目文件夹。

```text
我想在 VMAIL 框架中新建一个理论力学学习任务。

我想研究的真实对象或课本模型是：
【例如：自行车前叉减震、曲柄滑块机构、机械臂末端受力、双摆、滚动圆盘】

我关心的问题是：
【例如：改变阻尼系数后，车轮竖直加速度如何变化？】

我希望控制或改变的参数是：
【例如：质量、杆长、弹簧刚度、阻尼、摩擦系数、初始角度、驱动力矩】

我希望观察和导出的结果是：
【例如：某点位移、速度、加速度、角速度、关节力、驱动力矩、接触力、能量】

请你按照 VMAIL 的任务包规范，在 tasks/ 下创建一个新的学习任务文件夹。

要求：
1. 先把真实问题简化成理论力学模型，并写清楚简化假设。
2. 使用 MuJoCo MJCF 创建 model.xml。
3. 创建 task.yaml、parameters.yaml、observe.yaml、ui.yaml、notes.md。
4. 更新 tasks/manifest.yaml，让网页可以发现这个任务。
5. 参数必须有单位、范围、步长和说明；无量纲参数的单位写为 `1`。
6. 研究刚体上的固定点时，在 model.xml 中创建具名 site，并在 observe.yaml 的 sites 中声明位置、速度或加速度；不要用相邻帧差分代替 MuJoCo 点运动学。
7. 观测量必须对应模型中真实存在的 body、joint、site 或 equality。
8. 创建完成后，请运行必要检查，确认网页后端能够读取这个任务。
```

## 更新已有任务

```text
我想更新 VMAIL 中已有任务：
【任务 id】

我希望做的改变是：
【例如：增加一个连杆、增加摩擦、输出某点加速度、增加一个参数滑块、修改初始条件】

请你：
1. 阅读这个任务文件夹中的 task.yaml、model.xml、parameters.yaml、observe.yaml、ui.yaml、notes.md。
2. 按照 VMAIL 任务包规范修改文件。
3. 如果新增参数，请更新 parameters.yaml 和 ui.yaml。
4. 如果新增输出，请更新 observe.yaml 和 ui.yaml。
5. 如果改变了建模假设，请更新 notes.md。
6. 修改后检查任务能被网页读取并运行。
```

## 根据照片或草图建模

```text
我想根据一张照片或草图，在 VMAIL 中创建一个理论力学学习任务。

请先不要直接写代码。请先根据图片帮我完成：
1. 识别这个结构中可能重要的刚体、连接、约束和外力。
2. 提出一个适合理论力学课程学习的简化模型。
3. 说明哪些真实细节被忽略了，为什么可以忽略。
4. 建议我可以控制哪些参数。
5. 建议我可以观察哪些运动量、力或力矩。

在我确认后，先完整阅读 tasks/AGENTS.md 和 docs/task-package-spec.md，再按照 VMAIL 任务包规范创建任务文件夹。不要修改框架公共代码来适配单个任务。创建完成后更新 tasks/manifest.yaml，运行任务校验，并告诉我在网页中应该修改哪些参数、使用哪些控制、观察哪些曲线。
```
