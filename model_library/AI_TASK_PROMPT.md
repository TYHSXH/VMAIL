# 用资料库模型创建理论力学学习任务

复制下面的提示词，把方括号内容改成自己的选题，再交给 AI coding 工具。

```text
请以 model_library/[类别目录]/[模型目录]/ 中的 XML 为原始资料，
为 VMAIL 创建一个新的理论力学学习任务。

研究问题：[例如：UR5e 的末端负载增加时，不同伸展姿态下的关节静力矩如何变化？]
希望改变的量：[例如：末端负载、关节姿态、驱动速度]
希望观察的量：[例如：关节力矩、末端速度、质心位置、地面反力]

请先读取：
1. 该模型目录中的 SOURCE.md、LICENSE、dependencies.json；
2. tasks/AGENTS.md；
3. docs/task-package-spec.md。

先判断这个原始模型能否表达研究问题，并解释简化假设、单位、
惯性参数、接触、约束和驱动的物理含义。

资料库已补齐 XML 配套的网格、纹理等文件，复制时保留整个模型目录的相对结构。
请读取 SOURCE.md 与 resource_manifest.json，检查入口、插件、工作台 128 MiB 资源上限等兼容性问题；插件二进制和控制策略不包含在资料库内。
不要把缺资源、无法编译或浏览器不支持的模型说成可以直接运行。
不要为了动画效果随意删除惯性、接触、传动或闭环约束。
如需把复杂外形简化为基本几何体，必须明确说明质量、惯量和
碰撞形状如何处理，以及简化对本研究问题的影响。

把模型复制到新的 tasks/<task_id>/ 中开发，保留原始资料库不变，
并带上原始许可证、来源链接与版本号。
根据任务规范创建 task.yaml、parameters.yaml、observe.yaml、
ui.yaml、notes.md，并登记到 tasks/manifest.yaml。

页面参数与控制量用简短中文名并明确单位，曲线按物理量分组。
默认控制值应与初始状态及说明一致，给出能看清完整机构的默认视角。
研究点使用具名 site。不要把 freejoint 或球关节当成一维标量关节。
无法由现有网页直接支持的观测或控制，请如实说明；不要伪造字段或结果。

notes.md 要解释真实应用场景、模型与现实的差别、变量、观察方法、
理论推导思路和结果解读；公式用 Markdown/LaTeX 排版。
真实机器人模型不等同于经过实测校准的设备，也不要把官方原理示例
描述成通过了工业验证的真实案例。

最后按项目规范编译、校验，并说明哪些结论经过检查、哪些仍需验证。
```

## 以应用问题组织选题

| 应用问题 | 可选择的模型 | 可联系的力学知识 |
| --- | --- | --- |
| 工业机械臂伸长后为什么更难抬起重物？ | UR5e、iiwa、Z1 | 力矩平衡、重心、转动惯量、动力学耦合 |
| 移动机械臂何时容易倾覆？ | Stretch、TidyBot | 支撑范围、重心投影、外力与惯性力矩 |
| 双臂一起搬物体时如何分担载荷？ | ALOHA | 多刚体约束、受力平衡、内力与载荷分配 |
| 无人机如何同时保持悬停和改变姿态？ | Crazyflie、Skydio X2 | 力与力矩合成、角动量、转动惯量 |
| 四足机器人抬起一条腿后还能站稳吗？ | Go2、ANYmal C、Spot | 质心、支撑多边形、多点接触与摩擦 |
| 为什么夹爪夹得紧也可能滑落？ | Robotiq 2F-85、Shadow Hand | 法向力、摩擦、接触位置、欠驱动传动 |
| 差速小车如何转弯，会不会侧滑？ | 官方 car、Robot Soccer Kit | 速度合成、非完整约束、轮地摩擦 |
| 构件不再是刚体时，运动学会怎样变化？ | 柔性悬臂梁、斗杆、曲柄滑块 | 刚柔耦合、弹性变形、振动与阻尼 |
| 柔性滑轮如何传递运动和载荷？ | flex_pulley | 速度关系、张力与结构变形 |
| 缆索或线圈受扭、受拉后为什么振动？ | cable、coil、belt、pulley | 弯扭耦合、弹性势能、边界条件、张力 |

其中柔性体案例更适合进阶选题。应先确认原生 MuJoCo、浏览器 WASM 与网页渲染器的支持情况，再决定如何接入 VMAIL。本资料库已移除需要原生插件的案例。
