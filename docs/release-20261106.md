## 助手能力

- 默认开启 DeepSeek MAX 深度思考，完整回传工具调用所需的 reasoning_content；保存成功后继续验证、修复和总结。
- 实时展示 DeepSeek 返回的思考，正文、审批及完成时自动折叠，可重新展开；每条回复附本轮创建/修改文件和最终保存、清理状态，刷新后保留。
- 支持任务文件分段读取、分批创建、精确文本补丁、参数实验、任务数值 Python、保存与临时文件清理。
- 文件与命令先检查任务范围，再由学生选择本次同意、本轮同类操作同意或拒绝。脚本授权绑定源代码，审批期间修改脚本不会替换获准执行的内容。
- 本次对话文件列表累计显示创建/修改文件、差异和保存/清理状态；操作记录保留审批决定和计算结果，历史恢复不会重放操作。
- 只发布模型/任务文件，保留版本冲突保护、备份和回滚。临时工作区在结束、停止与断线后清理；服务重启会回收已退出进程遗留的受管工作区。
- 放开任务内 XML/OBJ、include、任务研究脚本及 MuJoCo 内建功能，保留平台格式、资源边界和计算上限。

任务终端提供任务校验、参数仿真和 math/NumPy/statistics/JSON 数值 Python，文件读写限定在任务副本；它不是任意系统 Shell 或完整 VS Code Python 环境。新建文件工具目前接收文本，二进制 STL/纹理仍需外部准备。完整主机终端需要另行接入操作系统隔离环境，不能仅依靠 cwd 或学生点同意实现任务范围约束。具体见[学生手册](user-guide.md#用-deepseek-对话创建任务)和[开发说明](development.md#本地-deepseek-助手)。
