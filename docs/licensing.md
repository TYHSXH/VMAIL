# Apache-2.0、MIT 与 GPL 的选择

本项目的平台代码与一般原创内容采用 **Apache-2.0**。**Logo 和学生作品明确排除，保留全部权利，不予公开授权，禁止商用**；第三方内容继续遵守原许可。学生优秀作品只在取得展示同意后展示，不向公众授予复用许可。详见 [版权与范围](../COPYRIGHT.md)和[贡献说明](../CONTRIBUTING.md)。

| 事项 | MIT | Apache-2.0 | GPL-3.0 |
| --- | --- | --- | --- |
| 允许商业使用或收费分发 | 是 | 是 | 是 |
| 通常可将衍生软件闭源分发 | 是，保留许可通知 | 是，遵守许可与通知条件 | 分发受 GPL 覆盖的修改／衍生软件时，通常须按 GPL 提供相应源码 |
| 保留版权和许可证 | 需要 | 需要，保留适用 NOTICE 并说明修改 | 需要，并履行相应源码与许可义务 |
| 明文专利授权 | 没有与 Apache 相同的明文专利条款 | 有，并含专利诉讼终止条款 | 有相关专利条款 |

三者都不能实现“默认禁止商用”。GPL 的重点是维持软件自由与分发时的源码义务，并不是禁止收费。Apache-2.0 适合本项目希望别人继续学习、修改和复用平台，同时保留来源、版权与明确许可的目标；它不要求所有衍生软件必须公开源码。

## 使用本项目时

- 分发获许可内容时提供 Apache-2.0 完整文本，保留适用的版权、来源和 NOTICE 通知；修改文件时明显说明修改。
- 第三方模型与素材按每组原许可使用，不能以本项目许可证覆盖其条件。Apache-2.0 不自动赋予对任何学生作品、教材题图或外部素材的权利。
- Logo 图像（含网页、任务地面和构建产物中的副本）不适用 Apache-2.0。未经课程组另行书面许可不得使用，禁止商用；法律规定的例外除外。复用平台代码时替换／移除 Logo 素材及相应引用，或先取得许可。
- 课程组与学生共有作品保留全部权利，不向公众授予复制、修改、再分发或商业使用许可。作品展示须取得全部相关权利人的展示同意，保留实际作者署名；展示或可下载不等于授权。

这是按内容划分授权范围，未修改 Apache-2.0 原文，也没有向 Apache-2.0 平台代码添加非商用条件。第三方原始许可仍然有效；本说明不撤销此前已经合法授予第三方的许可。
