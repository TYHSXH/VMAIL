# 学生使用手册

**VMAIL-BUAA · 理论力学虚拟仿真实验平台**。平台与标志版权归 **BUAA 5系 理论力学课程组**。项目主页与获取地址：[GitHub · TYHSXH/VMAIL](https://github.com/TYHSXH/VMAIL)。模型库中的第三方素材保留各自来源与许可证。

先完成安装，再选一个任务开始实验。左侧目录可直接跳转到需要的操作；具体题目的背景和要求请在实验台“任务”页阅读。

## 安装与启动

项目仓库：[TYHSXH/VMAIL](https://github.com/TYHSXH/VMAIL)。已安装 Git 的同学，在自己有读写权限的项目存放目录打开终端，执行：

```powershell
git clone https://github.com/TYHSXH/VMAIL.git
cd VMAIL
```

未安装 Git 时，也可从该仓库下载 ZIP 压缩包并完整解压。后续操作均在克隆或解压得到的项目文件夹中进行，保持内部目录结构不变。

1. Windows 电脑安装 **64 位 Python** ，建议使用 Python 3.12；安装时勾选加入 PATH。系统要求 Python 3.12 或更新版本，实际安装还取决于所用版本是否有匹配的依赖包。
2. 首次保持联网，在项目文件夹双击 `start.bat`；也可在上述终端执行 `.\start.bat`。程序会创建本机专用的 `.venv`，安装依赖并检查原生 MuJoCo 能否计算。
3. 浏览器会自动打开 <http://127.0.0.1:8000>。保留启动窗口；使用结束后在窗口按 Ctrl+C 停止服务。

以后仍双击 `start.bat`，环境正常时不会重新安装。学生无需安装 Node.js，也无需单独下载 MuJoCo：实时仿真在浏览器运行，批量计算使用同时安装的 Python 原生 MuJoCo。

**换电脑：** 复制项目文件，不复制 `.local`、`.venv`、`node_modules`、`.npm-cache` 和 `.git`。新电脑先安装 Python，再双击 `start.bat`。必须保留 `app`、`backend`、`docs`、`prompts`、`tasks`、`model_library`、`assets`、`licenses`、版权文件、`requirements.txt`、`constraints.txt` 及三个启动/安装 BAT 文件；已保存的实验结果可按需要一起复制。

如果已经使用 Conda，在目标环境安装 `requirements.txt` 后运行 `start-current-python.bat`；这种方式使用当前环境，不使用项目 `.venv`。

## 卸载与重新安装

先在启动窗口按 Ctrl+C 停止 VMAIL，再双击项目根目录的 `uninstall.bat`。脚本会删除一键安装创建的 `.venv`，一次清除其中的 Python 依赖，包括原生 MuJoCo；卸载不需要联网。

任务、实验结果、项目文件及 `.venv.backup-*` 旧环境备份会保留，系统 Python 和 Conda 环境不受影响。通过 `start-current-python.bat` 使用的外部环境不由此脚本卸载。若提示环境正在使用，请关闭相关程序后重试。

需要重新使用时，保持联网双击 `start.bat` 即可重建环境。若连项目文件也不再需要，可在备份实验结果后自行删除项目文件夹。

## 开始实验与视角操作

1. 点击左侧任务名称，先阅读右侧“任务”页。
2. 点击“开始仿真”运行动画并采集数据；可暂停、继续、单步或重置。达到设定时长后会自动暂停。
3. 左键旋转视角，Shift＋左键平移，滚轮缩放；也可切换工具栏中的“旋转”“平移”模式。“复位视角”恢复默认视角。

“拖动”模式用于调整物体起始姿态：按住物体拖动时暂停实验，不计时、不采集数据；松开后点击开始，从调整后的姿态和 t=0 运行。“重置”恢复任务原来的初始状态。

可拖动左右面板边缘调整宽度；“参数与数据”可收起或展开右侧面板。新增任务后点击左侧刷新按钮。

任务名称旁的编辑图标可修改名称，垃圾桶图标可删除整个任务。点击垃圾桶后还需要在弹窗中确认；选择“取消”或按 Esc 不会删除。确认删除会移除该任务的模型、配置及全部实验结果，不能通过网页恢复；后台计算中的任务需先等待完成或取消计算。若文件被其他程序占用而未完全清理，页面会提示残留目录。

## 用 DeepSeek 对话创建任务

点击顶部“AI 创建任务”或右侧“AI 助手”页签，在网页中描述研究对象、连接约束、已知条件、可变参数与观测结果。助手会先澄清建模条件，你可以继续补充或提问。

可用输入框下的“＋ 图片”选择题目图、机构草图或截图，也可将图片拖入网页，或在对话输入框粘贴剪贴板图片。发送前显示缩略图，可逐张移除；点击发送后图片才会随对话传给 DeepSeek，随对话保存在本机记录中。支持 PNG、JPEG、GIF、WebP，每条消息最多 4 张，每张最多 5 MB；单边最长 8192 像素。每次发送的上下文最多携带 8 张、合计 20 MB；过长时只发送近期上下文，较早图片仍在聊天记录中。图片会随多轮对话和后续任务生成继续作为上下文，可能增加 API 费用。

图片理解使用 **DeepSeek Flash**；V4 Pro 目前仅用于文字对话。如果选择了 Pro，请在连接设置中切换 Flash 并保存。图片与 XML 使用统一拖放分流：纯图片打开 AI 助手，单个 XML 打开模型预览，混合拖放会提示分开导入，不会互相误读。

首次使用展开“连接设置”，填写你自己在 [DeepSeek 开放平台](https://platform.deepseek.com/api_keys) 创建的 **API Key**，选择模型并保存；这里不填写 DeepSeek 账号密码。可点击“测试连接”验证密钥和模型访问权限。联网调用产生的费用由该 API 账户承担，对话和任务草稿会发送给 DeepSeek。

默认只在本次 Python 服务运行中保留密钥；关闭启动窗口后需重新绑定。可勾选“在这台电脑记住密钥”，使用当前 Windows 用户的加密能力保存到项目 `.local/`，不会写入网页源码、浏览器存储或任务文件。更换电脑或 Windows 用户后重新绑定；共享电脑使用结束前点击“解除绑定”。复制或分享项目时不要携带 `.local/`，Git 已忽略该目录。

直接与 DS 对话即可。例如描述“帮我创建一个单摆任务”，也可以先讨论受力、上传题图或逐次补充条件，不需要按固定流程点按钮。条件足够时，DS 会提交任务文件，网页在后台检查并试运行，成功后自动保存到 `tasks/<task_id>/`、登记到左侧列表，并显示程序的真实结果。

先在左侧选中任务，再说“修复这个任务的报错”“调整刚才模型的约束”或“增加一个观测量”，助手就能读取当前任务并在原编号下继续修改，无需重复新建。也可以直接指定已有任务编号。新对话仍能读取选中任务。

如果文件输出不完整或模型无法运行，错误会出现在对话中，可继续让助手修正。新建不会覆盖已有编号；修改只保存改动文件，保留其他配置、资源与实验结果。修改前会备份原文件到 `.local/task-history/<task_id>/`，校验失败时保留原任务。文件被其他操作修改后需重新读取；批量计算期间暂不保存修改。当前文件可展开查看，只讨论题目或概念时不会强制创建任务。

聊天不再以固定 40 条消息作为结束条件。较长时自动选择近期上下文，保留当前任务文件和修复问题，并提示有较早内容未随本次请求发送；完整聊天记录仍在页面中。较早条件可能需要重新说明。单条内容与每次请求仍有体积保护，模型本身也有有限上下文容量。

当前网页 AI 创建支持基础几何体与 `loads.yaml` 标准载荷，不接受外部网格、插件、文件引用或 Python 脚本。logo 资源由程序自动复制。复杂素材任务使用本地 AI 编程工具工作流；具体见[复杂几何体与 STL／MJCF 建模指南](mesh-modeling.md)。

对话文字、图片和草稿自动保存到 `.local/assistant-history.sqlite3`，刷新页面或重启后可恢复。在“历史对话”选择旧记录；“新对话”保留旧记录；“删除此对话”确认后只删除该对话及其图片、草稿，不删除已创建任务或实验结果。关闭页面前确认显示“已保存到本机”；读写失败会提示。记录以本地明文保存，不随项目分发。恢复旧对话后，任务操作对象仍以左侧当前选择或明确指定的任务编号为准。中断的轮次标记为未完成，不会自动重发或保存任务。生成或校验期间点击“停止等待”，本轮不进入保存；进入保存阶段后会完成写入，已发出的 API 请求仍可能计费。校验通过说明文件和默认工况可以运行，不代表物理建模正确，仍需用理论、单位和极限工况核对。

## 在 VS Code 中绑定 DS API

用 VS Code 打开整个 VMAIL 文件夹，按 [DeepSeek 官方 VS Code／Copilot 集成教程](https://api-docs.deepseek.com/quick_start/agent_integrations/github_copilot/)安装其链接的 DS 扩展及配置 Copilot 账号。在命令面板（Ctrl+Shift+P）执行 **DeepSeek: Set API Key**，输入自己的 Key，再在 Copilot Chat 的模型选择器中选择 DeepSeek。网页和编辑器的密钥绑定各自独立。其他兼容插件可使用 Base URL `https://api.deepseek.com` 与 `deepseek-flash`，具体字段以插件和官方文档为准。完整步骤见[项目首页](../README.md)。

需要本地创建任务时，先让 AI 阅读 `tasks/AGENTS.md`，复杂外形再读网格建模指南；学生准备 STL，AI 辅助写 MJCF，校验通过后回网页刷新任务。

## 参数、关节与控制

- **参数与控制 · 模型与初始条件：** 修改质量、刚度等参数及仿真时长、时间步长，然后点击“应用参数”。应用后模型重新加载。
- **关节姿态：** 在同一页上方用滑块或数值调整转动、滑动关节。转角可切换度/弧度；滑动位置使用米。调整时暂停且不记录数据，“恢复姿态”返回初始状态。闭环机构会联动其他关节，无法满足约束时会恢复原姿态。
- **参数与控制 · 运行控制与载荷：** 在同一页下方实时调节执行器输入。配置了自动载荷规律的任务会显示公式和完整时长的加载曲线；自动控制的输入不能再手动调整。

工具栏可显示外载荷、惯量、质心和关节轴。外载荷显示用于说明施力位置和方向，不代表合力；绿色箭头表示施加的力，紫色弧线表示力矩，灰色箭头连接拖动作用点与鼠标目标。数值以数据曲线及单位为准。

## 查看数据、导出与后台重算

开始仿真后自动进入“数据”页。曲线按物理量和单位分组，勾选框控制显示；悬停读取历史数值，Shift＋滚轮缩放时间轴，双击恢复全程。

- **先完整运行：** 设置模型参数、时长与步长并应用，再调整关节或拖动准备实际起点。从 t=0 运行到指定时长，自动暂停后才可导出。
- **导出本次实验 → 导出网页数据 CSV：** 直接下载这次网页已记录的完整数据，不重新计算。
- **导出本次实验 → 后台重算并下载 CSV：** 本机 Python 调用原生 MuJoCo，继承本次开始时的参数、时长、步长、完整姿态、速度与内部状态，并按仿真步重放中途执行器调节；按网页采样时刻输出，保存并下载 CSV。“后台重算”按钮是快捷入口。
- **已保存的实验：** 下载后台计算生成的 CSV。结果文件位于对应任务的 `results/run_*/`，关闭网页后仍保留。

| 区别 | 网页计算 | 后台重算（原批量计算） |
| --- | --- | --- |
| 引擎与用途 | 浏览器内的 MuJoCo WASM，方便交互、动画和曲线观察 | Python 调用本机原生 MuJoCo，方便复算、保存结果与实验条件 |
| 导出是否重算 | 不重算，直接下载本次记录 | 按同一次实验的起点和输入记录重新计算 |
| 精度 | 由模型、步长和求解设置决定 | 不因后台运行就天然更准确，同版本同条件应在数值误差范围内一致 |

两端当前使用 MuJoCo 3.13.0。网页帧率影响动画流畅度和运行速度，不应改变物理步长。后台不会从结束姿态再起跑，也不会用导出时刚改的新数值替换本次条件。完成后保留网页曲线并比较差异，结果目录还保存本次条件文件 `experiment.json`。接触、碰撞和敏感系统可能放大跨平台浮点误差，不能保证逐位相同；提高精度应检查模型、步长和求解设置，而不是默认相信某一端。

修改模型参数、时长、步长、关节姿态或再次拖动，需要重新完成网页仿真。“重新开始”沿用上次起始姿态；“重置”回到任务默认状态；“清空”清除曲线并回到本次起点。拖动是姿态准备，不把鼠标移动路径当作实验外载荷重放。模型或载荷文件已变更时拒绝重算旧记录。详见[网页计算、后台重算与导出说明](simulation-export.md)。

当前后台一次重算一组实验；多个参数组合的自动扫描需要另外编写实验脚本，可让 AI 协助完成。

计算过程中可查看进度或取消。单次最多 200000 步、2000000 个观测数值及 3600 秒仿真时间；后台计算超过 60 秒会终止。规模过大时缩短时长、减少观测量或适当增大步长；若模型不稳定，则检查参数并减小步长。

## 模型预览

点击顶部“模型预览”，可从模型库选择模型及入口，也可拖入一个 MuJoCo XML 文件。模型库优先选 `scene.xml` 等场景入口，并保留配套网格、纹理和 XML 文件。

预览支持视角操作、关节姿态调整、拖动和运行/暂停；不采集任务曲线、不保存实验结果。点击“退出预览”或按 Esc 返回实验台，原任务保持暂停。

库外 XML 如果依赖外部文件，单独拖入可能无法读取全部资源，需要将模型及依赖整理为完整任务。机器人模型未必带有平衡控制器，运行后倾倒不一定是软件故障。复杂模型运行较慢时，可关闭阴影、光照等显示效果。

## 让 AI 创建学习任务

需要从零编写 XML 时，可[下载默认 XML 模板（含灰色 logo）](/api/task-template)，模板已整合在现有的 `docs/task-package-spec.md` 中。让 AI 复制其中的默认 XML，并把 `assets/logos/logo-gray.png` 复制到任务的 `assets/logo-gray.png`，替换示例研究对象，保留地面中央显眼的 logo，再补齐任务配置。

向 AI 描述研究对象、简化假设、希望改变的参数和观察量，让它按项目的任务目录规则创建或修改学习任务。完成后在实验台刷新任务列表，再选择任务开展实验。

建模规范、载荷语法和开发说明保留在项目文件中，供 AI 或教师按需阅读。学生不需要先阅读这些技术文档。提示词示例和核对要点见[AI 使用与提示词](../prompts/student-task-builder.md)。

## 常见问题

- **找不到 Python 或版本不支持：** 安装 64 位 Python，建议 Python 3.12，并重新打开启动脚本。
- **首次安装失败：** 查看窗口里的具体报错，确认网络能访问 Python 软件包源，然后重新运行 `setup.bat`。
- **迁移后原环境不能运行：** 不要复用其他电脑的 `.venv`。安装脚本会检查失效或位置变更的环境，必要时将旧环境改名备份并重建。
- **原生 MuJoCo 自检失败：** 按安装窗口中的报错检查依赖或运行库；安装未完成前无法进行批量计算。
- **网页没有自动打开：** 保留启动窗口，手动访问 <http://127.0.0.1:8000>；若打不开，先看窗口是否报错。
- **8000 端口被占用：** 若 VMAIL 已启动，直接打开已有页面；否则关闭占用该端口的程序后重试。
- **页面还是旧界面：** 重启后台后强制刷新浏览器。运行包必须包含最新 `app` 文件夹。
- **右键手势拦截平移：** 切换“平移”模式后用左键操作，或使用 Shift＋左键。
- **新任务没有出现：** 让 AI 检查任务是否登记到全局索引，再点击任务列表刷新按钮。
